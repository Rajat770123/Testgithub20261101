# Testgithub20261101

A simple starter project for testing and learning GitHub repository workflows, now including a printable resume page.

## Description
This repository was created as a minimal project skeleton for experimenting with:
- GitHub repository setup
- version control practices
- project structure and documentation
- future feature development
- editable resume page creation

The resume page is available in `src/index.html` and is designed to be:
- easy to customize in the browser
- printable and exportable to PDF
- editable with in-place content changes
- saved locally in the browser for repeated editing

## Project Status
This project has moved beyond the initial starter stage and now includes a polished, editable resume page for personal or portfolio use.

## Resume Page
Open the resume page in a browser:

```bash
cd Testgithub20261101
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/src/index.html
```

You can edit the content directly on the page, then use the "Print / Save as PDF" button to generate a PDF version.

## Getting Started
Clone the repository:

```bash
git clone https://github.com/Rajat770123/Testgithub20261101.git
cd Testgithub20261101
```
Then open `src/index.html` in your browser to view and edit the resume page.
